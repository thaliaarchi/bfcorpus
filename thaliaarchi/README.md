# Brainfuck programs by Thalia Archibald

Brainfuck programs written by Thalia Archibald to test [bfrs](https://github.com/thaliaarchi/bfrs)
and for Codewars challenges.

- bfrs
  - [move_right.b](https://github.com/thaliaarchi/bfrs/blob/main/tests/move_right.b):
    A test for loop peeling.
  - [mul.b](https://github.com/thaliaarchi/bfrs/blob/main/tests/mul.b):
    A test for multiplication recognition, reduced from [../regehr/loop2.b](../regehr/loop2.b).
