# Brainfuck programs by copy

Brainfuck programs written by [copy](https://copy.sh/). They also made
[El Brainfuck](https://copy.sh/brainfuck/), a Brainfuck editor and optimizing
interpreter, a Brainfuck [text generator](https://copy.sh/brainfuck/text.html),
and a [program compressor](https://copy.sh/brainfuck/compress.html).

- [bfminifier.bf](https://copy.sh/stuff/brainfuck/bfminifier.bf)
- [div13.bf](https://copy.sh/stuff/brainfuck/div13.bf)
- [hammingweight.bf](https://copy.sh/stuff/brainfuck/hammingweight.bf)
- [euler06-brainfuck.bf](https://github.com/copy/project-euler/blob/master/euler06-brainfuck.bf)
