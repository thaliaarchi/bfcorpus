# Brainfuck programs by Laurent Vogel

Brainfuck programs written by Laurent Vogel and published on their [website](http://lvogel.free.fr/bf.html),
including entries in several competitions. They also wrote a Brainfuck
interpreter, bfli, which generates assembly code at runtime using GNU lightning,
and a Brainfuck interpreter in sed.

- ../bfgolf/: Several entries in Brainfuck Golf and Brainfuck Component
  Competition
- bfli/: Test programs for bfli [^bfli]
- bf-sed/: Test programs for bf-sed [^bf-sed]

[^bfli]: Split from test cases in test.sh in http://lvogel.free.fr/bf/bf-lightning-131011.zip
[^bf-sed]: Split from test cases in test.sh in http://lvogel.free.fr/bf/bf-sed.zip
