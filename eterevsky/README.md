# Busy beaver programs by Oleg Eterevsky

Busy beaver programs generated by Oleg Eterevsky's [beaver](https://github.com/eterevsky/beaver)
tool for proving non-termination of many classes of programs. They also wrote
[bfc](https://github.com/eterevsky/bfc), an optimizing compiler in C.
