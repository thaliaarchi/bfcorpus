# Brainfuck programs by Frans Faase

Brainfuck programs by Frans Faase, posted on their Brainfuck page at
[iwriteiam.nl](https://www.iwriteiam.nl/Ha_BF.html) and earlier at
[home.wxs.nl/~faase009](https://web.archive.org/web/20001203235300/http://home.wxs.nl/~faase009/Ha_BF.html).
Not all pages are included.

- [bfi.b](https://www.iwriteiam.nl/Ha_bf_inter.html): A Brainfuck interpreter
  written in Brainfuck, generated with [genbfi.c](https://www.iwriteiam.nl/Ha_genbfi_c.txt)
