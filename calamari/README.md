# Brainfuck programs by Jeffry Johnston

Brainfuck programs written by Jeffry Johnston aka calamari. They have
contributed many algorithms to the [Brainfuck algorithms](../esolang/algorithms/README.md)
page on the Esolang wiki.

They have also written several [Brainfuck interpreters](https://web.archive.org/web/20040416115444/http://lilly.csoft.net/~jeffryj/languages/languages.html),
most of which were not archived, and a [Brainfuck text generator](https://web.archive.org/web/20040308183813/http://lilly.csoft.net:80/~jeffryj/languages/textgen.java)
with genetic programming. They organized a Brainfuck [competition](https://sourceforge.net/p/brainfuck/discussion/201037/thread/38f82144/)
in 2005 with the theme a^n b^n c^n, but it was not archived.
