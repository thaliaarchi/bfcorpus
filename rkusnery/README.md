# Brainfuck programs by Ryan Kusnery

Brainfuck programs written by Ryan Kusnery at <pages.prodigy.net/rkusnery>, then
later at <members.tripod.com/rkusnery>.

- [Programs](https://web.archive.org/web/20001207035500/http://pages.prodigy.net/rkusnery/progs.html)
  - [bfc2.com](https://web.archive.org/web/20040614123658/http://pages.prodigy.net/rkusnery/bfc2.com),
    [bfc.txt](https://web.archive.org/web/20000817232939/http://pages.prodigy.net/rkusnery/bfc.html):
    Brainfuck compiler for MS-DOS, written in Brainfuck
  - Examples
    - Reverse text
    - Echo
- [Quine](https://web.archive.org/web/20000116041039/http://pages.prodigy.net/rkusnery/quines.html):
  A 1566-byte quine.
- ryanquine.b: The version of the quine included in [Panu Kalliokoski's](https://esoteric.sange.fi/brainfuck/bf-source/quine/ryanquine.b)
  archive and Ben Olmstead's [The Quines List](https://web.archive.org/web/20040204182345/http://www.mines.edu/students/b/bolmstea/quines/index.html#brainf),
  both with `#` debugging instructions and a comment referencing an earlier
  quine by Jason Reed.
- [99 Bottles of Beer](https://web.archive.org/web/20000116033651/http://pages.prodigy.net/rkusnery/beer.html)
