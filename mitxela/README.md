# Tic tac toe AI by mitxela

A [tic tac toe AI](https://github.com/mitxela/bf-tic-tac-toe) in Brainfuck
written by mitxela [[online demo](https://mitxela.com/projects/bf_tic_tac_toe)].
They also wrote [infrabuck](https://github.com/mitxela/infrabuck), a Brainfuck
compiler to Windows EXEs via fasm [[blog post](https://mitxela.com/projects/infrabuck)],
and an [online Brainfuck interpreter](https://mitxela.com/other/brainfuck).

- tictactoe.bf: Tic tac toe AI that can sometimes lose to keep it interesting
  (minified version).
- tictactoe-comments.bf: Original source with comments.
- choosenumber.bf: The choose-a-number script, which is minified in the full
  program.
