# Brainfuck programs by Erik Bosman

Brainfuck programs written by Erik Bosman, including the famous Mandelbrot set
fractal viewer. They also wrote some [Brainfuck utilities](https://esoteric.sange.fi/brainfuck/utils/bf-tools/)
in C: bfstrip, used to generate mandelbrot.b, and bf and bf16, 8- and 16-bit
Brainfuck interpreters which I do not include.

- [mandelbrot/](https://esoteric.sange.fi/brainfuck/utils/mandelbrot/):
  Mandelbrot set fractal viewer
  - mandelbrot.b: Prints a 128x48 ASCII rendering
  - mandelbrot-huge.b: Prints a 256x96 ASCII rendering
  - mandelbrot-titannic.b: Prints a 512x192 ASCII rendering

License: None for mandelbrot, GPL-2.0 for bfstrip
